Coach Clank privacy policy

Last updated: November 23, 2026

Coach Clank is a personal app used only by its owner. Nobody else signs in to it.

What it accesses

  • Google Calendar: reads events to know when the owner is busy, and creates or edits only the workout events it added itself.
  • Gmail: sends reminder emails to the owner. It does not read, search or delete email.

Where the data goes

Data from Google is stored only on the owner's own computer. It is not sold, shared, or used for advertising. Google user data is used only to provide the features above, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
